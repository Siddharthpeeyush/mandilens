# Data

## Source

Live data comes from the Government of India's Open Government Data platform:

- **Dataset:** *Current Daily Price of Various Commodities from various Markets (Mandi)* (Agmarknet)
- **Endpoint:** `https://api.data.gov.in/resource/9ef84268-d588-465a-a308-a864a43d0070`
- **Auth:** free API key from [data.gov.in](https://data.gov.in) → My Account → API Key Management,
  exported as `MANDILENS_DATA_GOV_KEY` (never committed — see `.gitignore`).

`src/fetch_prices.py` pulls Onion, Potato and Tomato across all reporting mandis
once a day into `data/raw/mandi_prices_YYYY-MM-DD.csv`.

## Sample data (current status)

Until the live API key is configured, `data/raw/` holds **synthetic sample data**
generated by `tools/make_sample.py` (seeded RNG, reproducible, clearly fake).
Every daily report and chart states its source, so sample vs live is never ambiguous.
The first successful live fetch replaces the sample feed going forward.

## Layout

| Path | Contents |
|---|---|
| `data/raw/` | One CSV per day, as fetched (or as generated by `make_sample.py`) |
| `data/processed/mandi_prices_clean.csv` | Tidy, deduplicated, analysis-ready dataset |

## Columns

`state, district, market, commodity, variety, grade, arrival_date (DD/MM/YYYY),
min_price, max_price, modal_price` — all prices in ₹/quintal.
